### ✅ Firebase Real-time Notifications

**Problem:**
- Notifications used polling every 10 seconds
- Delay up to 10s for new notifications
- Wasteful bandwidth usage

**Solution:**
- Integrated Firebase Realtime Database for instant notifications
- Backend pushes to Firebase when creating notifications
- Frontend subscribes to Firebase path with `onValue` listener
- Automatic fallback to polling if Firebase fails

**Backend Files:**
- `src/firebase/firebase.service.ts` - NEW: Firebase Admin SDK service
- `src/firebase/firebase.module.ts` - NEW: Global Firebase module
- `src/firebase/firebase-service-account.json` - NEW: Service account credentials
- `src/notifications/notifications.service.ts` - Updated to push to Firebase
- `src/app.module.ts` - Added FirebaseModule

**Frontend Files:**
- `frontend/src/utils/firebaseConfig.ts` - NEW: Firebase client config
- `frontend/src/components/HeaderNotifications.tsx` - Rewritten with Firebase listener

**Dependencies:**
- Backend: `firebase-admin@^12.0.0`
- Frontend: `firebase@^10.7.0`

**Security:**
- Added `firebase-service-account.json` to `.gitignore`
- Service account never committed to Git
