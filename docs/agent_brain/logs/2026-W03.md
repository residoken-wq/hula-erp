### ✅ Notification Deep Links

**Problem:** Clicking notifications just navigates to page, not specific content

**Solution:** Deep link params in URL → auto-open, scroll, highlight

**Backend Changes:**
- `src/sales/sales.service.ts` - Comment mentions: `/sales?order={id}&tab=INTERNAL&highlight=comment-{id}`
- `src/tasks/tasks.service.ts` - All task notifications: `/tasks?task={id}&highlight=task-{id}`

**Frontend Changes:**
- `frontend/src/pages/SalesPage.tsx` - Parse URL params, auto-open modal, pass to SalesOrderDetail
- `frontend/src/components/SalesOrderDetail.tsx` - Accept deepLink props, pass to SalesComments
- `frontend/src/components/sales/SalesComments.tsx` - Set default tab, scroll & highlight comment
- `frontend/src/pages/TasksPage.tsx` - Parse URL params, highlight row with animation
- `frontend/src/index.css` - `.highlight-row` animation
