# Agent Brain - Development Logs

Thư mục này chứa logs phát triển theo tuần để dễ quản lý và theo dõi.

## Cấu trúc

```
docs/agent_brain/
├── README.md           # File này
├── current_task.md     # Task đang thực hiện
└── logs/
    └── 2026-W02.md     # Log tuần 02/2026 (06-12 Jan)
```

## Quy ước đặt tên

- Log theo tuần: `YYYY-WXX.md` (ISO week number)
- Ví dụ: `2026-W02.md` = Tuần 2 năm 2026

## Cách sử dụng

1. Mỗi tuần tạo file log mới
2. Ghi nhận các features/fixes đã implement
3. Commit vào Git để sync giữa các devices
