# UI-UX Pro Max Skill

## When to Use
Use this skill whenever designing or implementing new frontend components, redesigning webapps or mobile modules, and when you need a professional, modern look.

## Core Design Resources

### 1. UI Styles (57 Styles)
When designing components, choose from modern styles such as:
- **Neo-Brutalism**: High contrast, bold borders, striking colors.
- **Glassmorphism**: Frosted glass effects, background blur, semi-transparent layers.
- **Neumorphism**: Soft UI, embossed and debossed shadows.
- **Minimalist Clean**: White space, simple typography, subtle grays.
- **Dark Mode Premium**: Deep dark backgrounds (e.g., `#0A0A0A`), glowing accents, low contrast text.

### 2. Color Palettes (95 Palettes)
Avoid standard reds/blues/greens. Use harmonious, tailored HSL colors:
- **Cyberpunk**: Neon Pink, Cyan, Electric Purple on deep dark backgrounds.
- **Earthy Organic**: Sage greens, warm terracottas, soft beige.
- **Corporate Sleek**: Deep navy, slate gray, crisp white, subtle electric blue accents.
- **Pastel Dream**: Soft lavenders, mint greens, peach.

### 3. Typography & Font Pairings (56 Pairs)
Use Google Fonts for a premium feel:
- **Headings / Body**:
  - `Inter` / `Inter` (Clean, modern tech)
  - `Playfair Display` / `Source Sans Pro` (Elegant, editorial)
  - `Outfit` / `Roboto` (Friendly, dynamic)
  - `Space Grotesk` / `Space Mono` (Developer-centric, techy)

### 4. UX Principles (98 Rules)
Adhere to strict UX guidelines:
- **Hierarchy**: Always use a single `<h1>`. Distinguish primary from secondary actions using visual weight (filled vs outlined buttons).
- **Accessibility**: Ensure minimum 4.5:1 contrast ratio for text. Add `aria-labels` to icon-only buttons.
- **Micro-interactions**: Add hover states (`transform: translateY(-2px)`, `box-shadow` changes) and transition durations (`ease-in-out 0.2s`) to interactive elements.
- **Feedback**: Provide immediate visual feedback for user actions (loading spinners, success toasts).
