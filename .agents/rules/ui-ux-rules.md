# Modern UI/UX Guidelines for Hula ERP Mobile & Web

When writing or modifying frontend code (React, TSX, CSS):
1. **Apply UI-UX Pro Max Principles**: Avoid generic designs. Use vibrant color palettes, modern Google Fonts (e.g., Inter, Outfit), and consistent spacing.
2. **Apply Antigravity Design**: Utilize glassmorphism (`backdrop-filter: blur`), floating elements with soft drop shadows, and subtle micro-interactions on hover/click.
3. **Google Stitch**: If a design from Google Stitch is referenced, strictly follow the structural and styling output generated by the Stitch canvas.
4. **Mobile First**: Since this is for the mobile webapp version of the modules, ensure all layouts are fully responsive, touch-friendly, and optimized for smaller screens.
